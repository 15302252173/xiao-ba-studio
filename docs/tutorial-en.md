# Niu Er Control Center · User Guide

> AI Agent Visual Management Platform — Control all your AI from one dashboard

---

## 🏠 Dashboard

### Daily Todos
- 📝 **Add**: Type in the input box + Enter or click ➕
- ✅ **Complete**: Click the circle to check off — completed items are struck through & dimmed
- ✏️ **Edit**: Click todo text to open edit modal
- 🗑️ **Delete**: Hover to reveal delete button
- 🔄 **Auto Rollover**: Undone items from yesterday automatically carry over to today, marked "Rolled over from yesterday"
- ⚠️ **Overdue Alert**: Red badge shows count of overdue items
- 📊 **Progress**: Real-time counter "3/5 completed" in the top right

### Instagram Downloader
- Paste Instagram Reel/Post URL
- Click "Extract Video"
- Auto-resolves → download or open in new tab
- ⚠️ If auto-resolve fails, a fallback button "Open in SSSInstagram" appears

### Agent Status
- Real-time monitoring of all AI Agent work statuses (Working / Idle / Sleeping)
- System health: CPU, Memory, Disk
- Gateway status: Online/Offline + latency
